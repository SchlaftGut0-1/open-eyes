Give your AI agent eyes on a real browser, while you watch.

open-eyes is a command line tool that lets an agent like Claude read and drive a visible Chromium window. You see every click as it happens, take over at any moment, and approve anything risky.

How it works

Reads the page as text

snapshot shows what is on screen, one element per line like button Save @3. --find searches the whole page, iframes included.

Acts like a person

Real mouse and keyboard events: click, fill, select, hover, scroll, upload, by ref or by name.

Shows you everything

The agent works in its own window. An overlay draws each action, and one click on Take control hands the browser back to you.

Your browser or its own

launch opens a separate profile. connect uses your everyday Chromium, Chrome, Brave or Edge with your logins, after you approve once.

Guardrails against prompt injection

You approve risky actions

Buying, sending, deleting, publishing, uploading a file or typing a password waits for your Allow in the agent window. Only real clicks answer.

You choose the sites

open-eyes policy sets allow and block lists, also for content embedded in iframes.

Everything is logged

open-eyes log lists every action and its outcome, never the text typed or the content of uploaded files.

Install

You need Node.js 22 or newer and Chromium, Chrome, Brave or Edge.

npm install -g https://github.com/SchlaftGut0-1/open-eyes/releases/download/v0.5.0/open-eyes-0.5.0.tgz
