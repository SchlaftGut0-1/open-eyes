Where 0.4.0 is not better

    How it was measured

    Both versions ran the same script back to back on the same machine: open each site, then record the tokens of the page as raw HTML, as visible text, as a screenshot, and as open-eyes' whole-page, default and --find snapshots. Three tasks then ran step by step. Tokens were counted with Anthropic's tokenizer; screenshots are estimated at width × height / 750. Live sites change between runs, so small differences on one page are noise.
